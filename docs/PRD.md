# 세상 돋보기 — PRD (Product Requirements Document)

> 버전: 1.0 | 작성일: 2026-02-15

---

## 1. 개요

### 1-1. 제품명

**세상 돋보기** — 초등학교 관찰 기록 웹 앱

### 1-2. 한 줄 설명

학생이 주변의 자연, 사물, 사람을 관찰하고 기록하면, AI 선생님이 즉시 칭찬 댓글을 달아주는 관찰 일지 플랫폼

### 1-3. 목표

| 목표 | 측정 지표 |
|------|----------|
| 학생의 관찰력·심미적 감수성·집중력 향상 | 관찰 일지의 분량 및 표현 다양성 증가 |
| 교사의 피드백 부담 경감 | AI가 전체 학생에게 1차 피드백 자동 제공 |
| 관찰 활동의 지속성 확보 | 일주일 이상 미션 기간 동안 매일 기록 유지율 |
| 간편한 수업 도구 제공 | 교사가 10분 내 미션 세팅 완료 |

### 1-4. 배경

초등학교 관찰 수업에서 반복되는 세 가지 문제를 해결하기 위해 기획되었다.

1. **학생**: "뭘 써야 할지 모르겠어요" — 관찰은 했지만 표현이 어려움
2. **교사**: "30명에게 일일이 피드백을 줄 수 없다" — 개별 피드백 시간 부족
3. **지속성**: "한 번 보고 끝" — 한 차시로 끝나는 관찰, 집중력 향상 기회 부재

## 2. 사용자 정의

### 2-1. 페르소나

#### 교사 (Teacher)

| 항목 | 설명 |
|------|------|
| 역할 | 초등학교 담임교사 |
| 목표 | 관찰 미션 출제, 학생 관리, 관찰 현황 파악 |
| 고충 | 30명 개별 피드백 불가, 종이 일지 수거·관리 번거로움 |
| 기술 수준 | 디지털 도구 기본 사용 가능, 개발 지식 없음 |

#### 학생 (Student)

| 항목 | 설명 |
|------|------|
| 역할 | 초등학교 3~6학년 학생 |
| 목표 | 관찰 일지 작성, 친구 관찰 감상 |
| 고충 | 글쓰기 어려움, 피드백 없는 기록은 흥미 저하 |
| 기술 수준 | 스마트폰 기본 사용 가능, 타이핑 미숙한 경우 있음 |

### 2-2. 사용자 흐름

#### 교사 흐름

```
회원가입(교사) → 대시보드 → 학생 계정 생성 → 초대 코드 전달
                    ↓
              미션 만들기 (제목 → AI 설명 생성 → 기간 설정 → 레이아웃 선택)
                    ↓
              미션 보드에서 학생 관찰 일지 확인
                    ↓
              갤러리에서 학년도별 전체 현황 파악
```

#### 학생 흐름

```
회원가입(학생) 또는 교사가 계정 생성 → 초대 코드로 반 참여
                    ↓
              홈에서 진행중 미션 선택
                    ↓
              관찰 일지 작성 (글 + 사진 + 음성 입력 + 날씨)
                    ↓
              제출 → AI 칭찬 댓글 팝업
                    ↓
              갤러리에서 친구 관찰 감상 / 내 기록에서 이전 글 확인
```

## 5. 기술 스택

### 5-1. 프론트엔드

| 기술 | 용도 |
|------|------|
| **Next.js 14** | React 프레임워크, App Router |
| **TypeScript** | 타입 안정성 |
| **Tailwind CSS** | 스타일링 |
| **Web Speech API** | 음성 입력 (SpeechRecognition) |

### 5-2. 백엔드 / 인프라

| 기술 | 용도 |
|------|------|
| **Firebase Authentication** | 사용자 인증 |
| **Cloud Firestore** | 데이터베이스 (NoSQL) |
| **Firebase Storage** | 이미지 저장 |
| **Vercel** | 배포 및 호스팅 |
| **Next.js API Routes** | 서버 사이드 API (AI 호출) |

### 5-3. AI

| 기술 | 용도 |
|------|------|
| **Google Gemini 2.0 Flash** | AI 칭찬 댓글 생성, 미션 설명 생성 |
| **@google/generative-ai** | Gemini SDK |
| **멀티모달 입력** | 텍스트 + 이미지 동시 분석 |

### 5-4. 아키텍처 결정 사항

| 결정 | 이유 |
|------|------|
| Firebase Client SDK only (Admin SDK 미사용) | 서버리스 환경, 간단한 구조 유지 |
| Secondary Firebase App 패턴 | 교사가 학생 계정 생성 시 교사 로그아웃 방지 |
| Firebase 지연 초기화 (getter 함수) | 빌드 타임 에러 방지, 환경 변수 안전 로딩 |
| 학년도 클라이언트 계산 | 서버 없이 `getAcademicYear()` 함수로 3월~2월 기준 계산 |
| API Routes로 AI 호출 | Gemini API 키를 클라이언트에 노출하지 않음 |

## 6. 데이터 모델

### 6-1. Firestore 컬렉션 구조

```
/users/{uid}
{
  uid: string
  name: string
  email: string
  role: "teacher" | "student"
  classId: string
  previousClassIds: string[]     // 이전 학급 이력
  managedPassword?: string       // 교사가 생성한 계정의 비밀번호

```

```
/missions/{missionId}
{
  id: string

```

### 6-2. 핵심 비즈니스 로직

#### 학년도 계산

```
학년도 = (현재 월 >= 3월) ? 올해 : 작년
예: 2026년 1월 → 2025학년도
    2026년 3월 → 2026학년도
```

#### classId와 초대 코드

```
classId: 20자 랜덤 영숫자 문자열
초대 코드: classId 앞 6자리
예: classId = "aB3kF9xT2mPq7wLnYh4s" → 초대 코드 = "aB3kF9"
```

#### 미션 기간 제한

```
오늘 날짜가 startDate ~ endDate 범위 내 → 글쓰기 가능
범위 밖 → 미션 카드 비활성, 글쓰기 페이지 접근 차단
```

## 8. AI 프롬프트 설계

### 8-1. AI 칭찬 댓글

**역할**: 따뜻하고 격려하는 초등학교 선생님

**입력**: 학생의 관찰 일지 텍스트 + 첨부 사진 (최대 3장)

**출력 규칙**:
- 3~4문장
- 학생이 관찰한 구체적인 내용을 짚어 칭찬
- 다음 관찰을 유도하는 질문 1개 포함
- 다른 감각(촉각, 후각 등)으로의 확장 유도
- 반말 사용 (초등학생 대상)

**출력 예시**:
> "와, 꽃잎의 안쪽과 바깥쪽 색깔이 다르다는 걸 발견했구나! 정말 자세히 관찰했어. 혹시 꽃잎을 만져보면 느낌도 다를까? 다음에 한번 살짝 만져보고 알려줘!"

### 8-2. AI 미션 설명 생성

**입력**: 미션 제목 (예: "봄의 식물 관찰")

**출력 규칙**:
- 5~7문장의 학생 안내문
- 관찰 방법 안내
- 느낌과 생각을 함께 기록하도록 유도
- 이모지 2~3개 포함

## 10. 제약 사항 및 리스크

| 항목 | 내용 | 대응 방안 |
|------|------|----------|
| 음성 입력 브라우저 제한 | Web Speech API는 Chrome만 완전 지원 | 사용 안내에 Chrome 권장 명시 |
| AI 응답 지연 | Gemini API 응답이 느릴 수 있음 | 단계별 로딩 메시지로 UX 보완 |
| AI API 비용 | 사용량 증가 시 비용 발생 | Gemini 2.0 Flash (저비용 모델) 사용 |
| AI 부적절 응답 | AI가 교육적이지 않은 답변 생성 가능성 | 시스템 프롬프트로 역할·톤 엄격 제한 |
| Firebase 무료 한도 | Firestore 읽기/쓰기, Storage 용량 제한 | 학급 규모(30명) 기준 무료 한도 내 운영 가능 |
| 학생 개인정보 | 초등학생 사진·글 포함 | 공개/비공개 설정, 교사만 전체 접근 |
