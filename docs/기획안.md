# 세상 돋보기 - 프로젝트 기획안

## 초등학교 자연 관찰 기록 웹 앱

---

## 1. 프로젝트 개요

### 1-1. 프로젝트명
**세상 돋보기** - 초등학교 자연 관찰 기록 웹 앱

### 1-2. 기획 배경

초등학교 과학 교육과정에서 자연 관찰 활동은 핵심적인 학습 요소이다. 그러나 현재 관찰 기록 방식에는 다음과 같은 문제점이 있다.

| 문제점 | 현황 |
|--------|------|
| 기록 방식의 한계 | 종이 관찰 일지는 사진 첨부가 어렵고, 보관 및 공유가 불편함 |
| 피드백 지연 | 교사 1인이 30명 이상의 관찰 일지에 일일이 피드백을 주기 어려움 |
| 동기 부여 부족 | 관찰 일지를 써도 즉각적인 반응이 없어 학생의 흥미가 떨어짐 |
| 공유의 부재 | 친구들의 관찰 결과를 함께 보며 배우는 기회가 제한됨 |

### 1-3. 기획 목적

1. **디지털 관찰 기록**: 사진과 글을 결합한 멀티미디어 관찰 일지 작성 환경 제공
2. **AI 즉각 피드백**: 학생이 글을 올리면 AI가 즉시 칭찬과 질문으로 응답하여 관찰 동기 유지
3. **공유와 소통**: 갤러리를 통해 친구들의 관찰을 함께 감상하고 배우는 장 마련
4. **교사 업무 경감**: 미션 생성, 학생 관리, 일지 확인을 하나의 플랫폼에서 처리

### 1-4. 대상 사용자

| 역할 | 대상 | 주요 니즈 |
|------|------|----------|
| 교사 | 초등학교 담임교사 | 미션 출제, 학생 관찰 일지 확인, 학급 관리 |
| 학생 | 초등학교 3~6학년 | 관찰 일지 작성, 사진 업로드, 친구 일지 감상 |

## 2. 핵심 기능 설계

### 2-1. 사용자 역할 및 권한

```
┌─────────────┐     ┌─────────────┐
│    교사      │     │    학생      │
├─────────────┤     ├─────────────┤
│ 미션 생성    │     │ 관찰 일지 작성│
│ 미션 관리    │     │ 일지 수정    │
│ 학생 계정 생성│     │ 갤러리 감상  │
│ 학생 관리    │     │ 내 기록 보기  │
│ 갤러리 관리  │     │ 반 참여      │
│ 게시물 삭제  │     │              │
└─────────────┘     └─────────────┘
```

### 2-2. 주요 기능

#### A. 학급 관리 시스템

- **초대 코드 방식**: 교사에게 6자리 초대 코드 발급 → 학생이 코드 입력으로 반 참여
- **학년도 관리**: 3월~다음해 2월 기준 학년도 자동 계산
- **새 학급 전환**: 새 학년 시작 시 새 학급 생성, 이전 데이터 보관

#### B. 관찰 미션 시스템

- **미션 생성**: 교사가 주제, 기간, 보드 레이아웃 설정
- **AI 미션 설명 생성**: 미션 제목을 입력하면 AI가 학생 눈높이에 맞는 안내 문구 자동 생성
- **기간 제한**: 시작일~마감일 사이에만 학생 글쓰기 허용
- **보드 레이아웃**: 담벼락형 / 스트림형 / 격자형 3가지 보기 방식

#### C. 관찰 일지 작성

- **멀티미디어 기록**: 텍스트 + 사진(최대 5장) + 날씨 + 관찰 날짜
- **음성 입력**: Web Speech API를 활용한 한국어 음성 인식 (초등학생 타이핑 부담 감소)
- **공개/비공개 설정**: 갤러리 공개 여부 선택 가능

#### D. AI 칭찬 댓글

- **즉각 피드백**: 학생이 관찰 일지를 제출하면 AI가 즉시 칭찬 댓글 생성
- **멀티모달 분석**: 글 내용뿐 아니라 첨부 사진도 함께 분석하여 구체적 칭찬
- **호기심 자극**: 칭찬과 함께 관찰 내용과 관련된 질문을 던져 탐구심 유도
- **팝업 모달**: AI 댓글이 모달로 표시되어 학생이 바로 확인 가능

#### E. 갤러리

- **학년도별 탭**: 게시물이 있는 학년도별로 탭 전환
- **다양한 레이아웃**: 담벼락형(패들렛 스타일), 스트림형(타임라인), 격자형(그리드)
- **모바일 최적화**: 모바일에서는 자동으로 스트림형 표시
- **교사/학생 뷰 분리**: 교사는 전체 글 확인, 학생은 공개 글 + 본인 글만 표시

#### F. 학생 계정 관리

- **교사 대리 생성**: 초등학생의 회원가입 어려움을 고려, 교사가 계정 일괄 생성
- **자동 이메일/비밀번호 생성**: 학생 이름만 입력하면 계정 자동 생성
- **계정 정보 복사**: 생성된 계정 정보를 한 번에 복사하여 학생에게 전달
- **계정 수정/삭제**: 교사가 생성한 계정의 이메일, 비밀번호 변경 가능

## 3. 기술 설계

### 3-1. 기술 스택

| 구분 | 기술 | 선택 이유 |
|------|------|----------|
| 프론트엔드 | Next.js 14 (React) | 서버 컴포넌트, API Routes 지원 |
| 스타일링 | Tailwind CSS | 빠른 UI 개발, 반응형 디자인 |
| 인증 | Firebase Authentication | 이메일/비밀번호 인증, 간편한 사용자 관리 |
| 데이터베이스 | Cloud Firestore | 실시간 NoSQL, 클라이언트 SDK로 직접 접근 |
| 파일 저장 | Firebase Storage | 이미지 업로드 및 URL 관리 |
| AI | Google Gemini (gemini-2.0-flash) | 한국어 지원, 멀티모달(텍스트+이미지), 빠른 응답 |
| 배포 | Vercel | Next.js 최적 배포, 자동 CI/CD |
| 음성 인식 | Web Speech API | 브라우저 내장, 별도 라이브러리 불필요 |

### 3-2. 시스템 구조

```
[사용자 (브라우저)]
       │
       ▼
[Next.js 프론트엔드] ──── [Vercel 배포]
       │
       ├── Firebase Auth (인증)
       ├── Cloud Firestore (데이터)
       ├── Firebase Storage (사진)
       │
       └── API Routes
              │
              ├── /api/ai-comment (AI 칭찬 댓글)
              └── /api/ai-description (AI 미션 설명)
                      │
                      ▼
               [Google Gemini API]
```

## 5. AI 활용 설계

### 5-1. AI 칭찬 댓글

| 항목 | 내용 |
|------|------|
| 모델 | Google Gemini (gemini-2.0-flash) |
| 입력 | 학생 이름, 미션 제목, 관찰 내용, 사진 (최대 3장) |
| 출력 | 3~4문장의 칭찬 댓글 + 호기심 질문 1개 |
| 말투 | 초등학생 눈높이의 쉽고 따뜻한 말투 |
| 특징 | 사진이 있으면 사진 내용도 분석하여 언급 (멀티모달) |

**시스템 프롬프트:**
> 당신은 다정하고 호기심 많은 초등학교 선생님입니다.
> 학생의 관찰 내용 중 구체적인 부분을 골라 진심으로 칭찬하고,
> 호기심을 자극하는 질문을 딱 하나 던져주세요.

### 5-2. AI 미션 설명 생성

| 항목 | 내용 |
|------|------|
| 모델 | Google Gemini (gemini-2.0-flash) |
| 입력 | 미션 제목 |
| 출력 | 5~7문장의 관찰 안내문 |
| 특징 | 느낀 점/생각을 함께 적도록 유도하는 문장 포함 |

## 7. 기대 효과

### 교육적 효과

1. **관찰 습관 형성**: 주기적 미션을 통해 자연 관찰을 생활화
2. **즉각적 피드백**: AI 칭찬 댓글로 관찰 활동에 대한 즉각적 긍정 강화
3. **또래 학습**: 갤러리에서 친구들의 관찰을 보며 다양한 시각 습득
4. **디지털 리터러시**: 멀티미디어 기록 활동을 통한 디지털 역량 향상

### 교사 업무 효율화

1. **미션 관리 간소화**: AI 설명 생성, 기간 자동 관리
2. **피드백 부담 감소**: AI가 1차 피드백 제공, 교사는 심층 피드백에 집중
3. **학생 관리 편의**: 계정 일괄 생성, 초대 코드 방식의 간편한 학급 구성
4. **데이터 보관**: 학년도별 갤러리로 관찰 기록 체계적 보관
