# 세상 돋보기 - 바이브코딩 프롬프트 문서

> 이 문서는 AI 코딩 도구(Claude, ChatGPT, Cursor 등)에게 순서대로 입력하여
> "세상 돋보기" 웹 앱을 처음부터 만들 수 있는 프롬프트 모음입니다.

---

## STEP 1. 프로젝트 초기 설정

```
Next.js 14 + TypeScript + Tailwind CSS 프로젝트를 생성해줘.

프로젝트 이름: observation-log
앱 이름: "세상 돋보기"
설명: 초등학교 자연 관찰 기록 웹 앱

Firebase를 사용할 거야:
- Firebase Authentication (이메일/비밀번호 인증)
- Cloud Firestore (데이터베이스)
- Firebase Storage (이미지 저장)

Firebase는 클라이언트 SDK만 사용하고, Admin SDK는 사용하지 않아.
Firebase 설정은 환경 변수(.env.local)로 관리해줘.

필요한 npm 패키지: firebase, date-fns, @google/generative-ai
```

## STEP 3. 타입 정의

```
다음 데이터 타입을 정의해줘.

파일: src/types/db.ts, src/types/index.ts

1. User (사용자)
   - uid, name, email, role("teacher"|"student"), classId,
     previousClassIds?(string[]), managedPassword?(string), createdAt

2. Mission (미션)
   - id, classId, title, description?, weekLabel?, layoutType("wall"|"stream"|"grid"),
     exampleImageUrl?, startDate, endDate, isActive, createdAt, updatedAt

3. Post (게시물)
   - id, authorId, authorName, missionId, classId, content, photoUrls(string[]),
     weather(WeatherType), observedAt, isPublic, academicYear?, createdAt, updatedAt

4. Comment (댓글)
   - id, postId, authorType("ai"|"teacher"|"student"), authorId?(null for AI),
     authorName, content, createdAt

5. Gallery
   - id, classId, academicYear, status("open"|"closed"), createdAt, closedAt?

6. WeatherType = "sunny"|"cloudy"|"rainy"|"snowy"|"windy"
7. LayoutType = "wall"|"stream"|"grid"

날씨 옵션 상수 WEATHER_OPTIONS와 레이아웃 옵션 상수 LAYOUT_OPTIONS도 만들어줘.
각각 value, label, emoji(날씨만), description(레이아웃만) 포함.
```

## STEP 4. Firestore CRUD 함수

```
Firestore CRUD 함수를 만들어줘.

파일: src/lib/firestore.ts

1. 헬퍼:
   - getAcademicYear(date?): 학년도 계산 (3월~2월 기준, getMonth() >= 2면 올해, 아니면 작년)

6. Galleries: createGallery, closeGallery, reopenGallery, getGalleriesByClass

여러 classId를 지원하는 함수도 필요해:
- getGalleriesByClassIds, getPostsByClassIds, getAllPostsByClassIds

## STEP 19. AI 기능 (Gemini)

```
Google Gemini AI 기능을 구현해줘.

파일: src/utils/ai.ts
환경 변수: GOOGLE_GEMINI_API_KEY (서버사이드 전용, NEXT_PUBLIC 없음)
모델: gemini-2.0-flash

1. generateAIComment(authorName, missionTitle, content, photoUrls[])
   - 시스템 프롬프트: "다정하고 호기심 많은 초등학교 선생님" 역할
   - 학생의 관찰 내용 중 구체적 부분을 칭찬 + 호기심 자극 질문 1개
   - 3~4문장, 이모지 1~2개, 초등학생 눈높이
   - 사진이 있으면 fetch로 가져와서 base64 변환 후 멀티모달 전송 (최대 3장)
   - 429 에러 시 최대 3회 재시도 (3초 간격)

2. generateMissionDescription(title)
   - 시스템 프롬프트: "초등학교 자연 관찰 수업 베테랑 교사" 역할
   - 관찰 대상, 방법 안내 + 느낀 점/생각 적도록 유도
