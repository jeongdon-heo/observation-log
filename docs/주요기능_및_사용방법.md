## 1. 앱 소개

**세상 돋보기**는 초등학생이 주변의 자연, 사물, 사람을 관찰하고 기록하면, AI 선생님이 즉시 칭찬 댓글을 달아주는 관찰 일지 웹 앱입니다.

### 핵심 기능 한눈에 보기

| 기능 | 설명 |
|------|------|
| 관찰 미션 출제 | 교사가 관찰 주제와 기간을 설정 |
| 관찰 일지 작성 | 학생이 사진 + 글 + 음성으로 기록 |
| AI 칭찬 댓글 | 글 제출 즉시 AI가 구체적으로 칭찬 |
| 반 갤러리 | 친구들의 관찰을 함께 감상 |
| 학생 계정 관리 | 교사가 학생 계정을 일괄 생성 |

### 사용자 역할

- **교사**: 미션 출제, 학생 관리, 갤러리 관리
- **학생**: 관찰 일지 작성, 갤러리 감상, 내 기록 확인

## 2. 회원가입과 로그인

### 2-1. 회원가입

1. 첫 화면에서 **"회원가입"** 버튼 클릭
2. 이름, 이메일, 비밀번호(6자 이상) 입력
3. 역할 선택: **"선생님"** 또는 **"학생"**
4. **"회원가입"** 버튼 클릭

> 학생 계정은 교사가 대신 만들어줄 수 있습니다. (3-4. 학생 관리 참고)

### 2-2. 로그인

1. 이메일과 비밀번호 입력
2. **"로그인"** 버튼 클릭
3. 역할에 따라 자동으로 대시보드로 이동
   - 교사 → 교사 대시보드
   - 학생 → 학생 홈

## 3. 교사 기능

### 3-1. 대시보드

로그인 후 첫 화면입니다. 다음 정보를 한눈에 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 전체 미션 | 만든 미션 수 |
| 진행중 미션 | 현재 진행 중인 미션 수 |
| 학생 수 | 반에 가입한 학생 수 |
| 학급 초대 코드 | 학생에게 알려줄 **6자리 코드** |

**학급 초대 코드**는 대시보드 하단에 크게 표시됩니다. 이 코드를 학생들에게 알려주면, 학생이 앱에서 반에 참여할 수 있습니다.

---

### 3-2. 미션 관리

상단 메뉴 **"미션 관리"** 에서 관찰 미션을 만들고 관리합니다.

#### 새 미션 만들기

| 입력 항목 | 설명 | 필수 여부 |
|-----------|------|----------|
| 미션 제목 | 관찰 주제 (예: "봄의 식물 관찰") | 필수 |
| 설명 | 학생 안내문. **"AI 설명 생성"** 버튼으로 자동 작성 가능 | 필수 |
| 주차 라벨 | 예: "1주차", "4월 2주" | 선택 |
| 예시 이미지 | 관찰 예시 사진 업로드 | 선택 |
| 보드 레이아웃 | 담벼락형 / 스트림형 / 격자형 | 필수 |
| 시작일 | 학생이 글을 쓸 수 있는 시작 날짜 | 필수 |
| 마감일 | 학생이 글을 쓸 수 있는 마감 날짜 | 필수 |

**미션 기간 설정**
- 시작일~마감일 사이에만 학생이 글을 작성할 수 있습니다.
- 기간 밖에서는 미션 카드에 "시작 전" 또는 "마감" 배지가 표시되고, 학생은 글쓰기 페이지에 접근할 수 없습니다.
- 일주일 이상의 기간을 설정하면 학생의 지속적 관찰과 집중력 향상에 효과적입니다.

#### 미션 보드 보기

미션 카드를 클릭하면 학생들이 작성한 관찰 일지를 볼 수 있습니다.

- 상단 레이아웃 전환 버튼으로 보기 방식 변경 가능 (담벼락 / 스트림 / 격자)
- 부적절한 게시물은 **"삭제"** 버튼으로 삭제 가능

---

### 3-3. 갤러리

상단 메뉴 **"갤러리"** 에서 모든 학생의 관찰 일지를 학년도별로 볼 수 있습니다.

- **학년도 탭**으로 연도 전환 (학년도: 3월 ~ 다음해 2월)
- 학생이 글을 작성한 학년도에 자동으로 분류됩니다.
- 이전 학급의 게시물도 함께 표시됩니다.
- 게시물 삭제가 가능합니다.

---

### 3-4. 학생 관리

상단 메뉴 **"학생 관리"** 에서 학생 계정을 만들고 관리합니다.

#### 학생 계정 만들어주기

초등학생이 직접 회원가입하기 어려운 경우, 교사가 대신 계정을 만들 수 있습니다.

1. **학생 이름** 입력 후 **"추가"** 버튼 클릭
2. 이메일과 비밀번호가 **자동 생성**됨
   - 이메일 형식: `s랜덤6자리@obs.school`
   - 비밀번호: 랜덤 6자리 숫자
3. 생성된 계정 정보가 표에 표시됨
4. **"전체 복사"** 버튼으로 정보를 복사해 학생에게 전달

> 이메일/비밀번호를 직접 지정하려면 "이메일/비밀번호 직접 설정"을 펼쳐 입력하세요.

#### 학생 계정 수정

- 교사가 만든 계정은 **"수정"** 버튼으로 이메일/비밀번호 변경 가능
- 학생이 직접 가입한 계정은 수정 불가

#### 학생 삭제

1. 삭제할 학생의 체크박스 선택 (전체 선택 가능)
2. **"선택 삭제"** 버튼 클릭
3. 삭제 후에도 해당 학생의 작성 글과 댓글은 유지됨

---

### 3-5. 학급 관리

#### 새 학급 만들기

새 학년이 시작되면:

1. 대시보드 하단의 **"새 학급 만들기"** 버튼 클릭
2. 새로운 초대 코드가 발급됨
3. 이전 학급의 게시물은 갤러리에서 계속 열람 가능

#### 이전 학급 연결

다른 기기에서 사용하던 이전 학급의 갤러리를 연결할 수 있습니다.

1. 이전 학급의 초대 코드 입력
2. 해당 학급의 게시물이 갤러리에 통합 표시됨

---

## 4. 학생 기능

### 4-1. 반 참여하기

처음 로그인하면 반 참여 화면이 표시됩니다.

1. 선생님이 알려준 **6자리 초대 코드** 입력
2. **"반 참여하기"** 버튼 클릭
3. 완료되면 홈 화면에 미션 목록이 표시됨

---

### 4-2. 관찰 일지 쓰기 (핵심 기능)

홈 화면에서 **진행중인 미션 카드**를 눌러 글쓰기 페이지로 이동합니다.

#### 작성 항목

| 항목 | 설명 | 필수 여부 |
|------|------|----------|
| 관찰 내용 | 관찰한 것을 글로 작성 | 필수 |
| 사진 첨부 | 관찰 대상 사진 (최대 5장) | 선택 |
| 오늘 날씨 | ☀️ 맑음 / ☁️ 흐림 / 🌧️ 비 / ❄️ 눈 / 💨 바람 | 필수 |
| 관찰 날짜 | 기본값: 오늘 (변경 가능) | 필수 |
| 공개 여부 | 켜짐: 친구에게 공개 / 꺼짐: 선생님만 | 필수 |

#### 음성 입력 기능

타이핑이 어려운 학생을 위한 음성 입력을 지원합니다.

1. **"🎤 음성 입력"** 버튼 클릭
2. "🔴 듣는 중..." 상태에서 말하기
3. 말하기를 마치면 자동으로 텍스트 변환
4. 더 말하려면 버튼을 다시 클릭

> 크롬 브라우저에서 사용해주세요. 마이크 권한 허용이 필요합니다.

#### 글 제출 과정

**"관찰 일지 올리기"** 버튼을 누르면 다음 단계가 자동 진행됩니다:

```
① 사진 업로드 중...
   ↓
② 관찰 일지 저장 중...
   ↓
③ AI 선생님이 댓글을 달고 있어요...
   ↓
④ AI 칭찬 댓글 팝업 표시!
```

AI 댓글 팝업에서 "확인"을 누르면 홈으로 돌아갑니다.

---

### 4-3. 내 기록 보기

하단 **"📓 내 기록"** 탭에서 내가 작성한 모든 관찰 일지를 볼 수 있습니다.

- **"수정"** 버튼으로 글 수정 가능 (내용, 사진, 날씨, 공개 여부 등)
- AI 선생님의 칭찬 댓글도 확인 가능

---

### 4-4. 갤러리 구경하기

하단 **"🖼️ 갤러리"** 탭에서 우리 반 친구들이 공개한 관찰 일지를 구경할 수 있습니다.

- 친구들이 공개한 글이 표시됨
- 내가 비공개로 쓴 글은 나에게만 보임
- 학년도 탭으로 연도별 필터링 가능

## 5. AI 기능

### 5-1. AI 칭찬 댓글

학생이 관찰 일지를 올리면, AI 선생님(Google Gemini)이 **즉시** 칭찬 댓글을 생성합니다.

**AI 댓글의 특징:**
- 학생의 글과 사진을 **함께 분석**하여 구체적으로 칭찬
- 다음 관찰을 유도하는 **질문** 포함
- 3~4문장의 따뜻하고 격려하는 톤
- 글 제출 후 자동으로 팝업 표시

**예시:**
> "와, 꽃잎의 색깔이 안쪽과 바깥쪽이 다른 걸 발견했구나! 정말 자세히 관찰했어. 혹시 꽃잎을 만져보면 느낌도 다를까? 다음에 한번 만져보고 알려줘!"

### 5-2. AI 미션 설명 생성

교사가 미션을 만들 때, 제목만 입력하면 AI가 학생 안내문을 자동 작성합니다.

1. 미션 제목 입력 (예: "봄의 식물 관찰")
2. **"AI 설명 생성"** 버튼 클릭
3. AI가 5~7문장의 관찰 안내문 생성
4. 느낌과 생각을 표현하도록 유도하는 문구 포함

## 6. 갤러리와 보드 레이아웃

### 6-1. 세 가지 보드 레이아웃

교사가 미션별로 보드 레이아웃을 선택할 수 있습니다.

| 레이아웃 | 설명 | 추천 상황 |
|----------|------|----------|
| **담벼락형 (Wall)** | 패들렛처럼 카드가 자유롭게 배치 | 다양한 관찰을 한눈에 볼 때 |
| **스트림형 (Stream)** | 시간순으로 세로 나열 | 순서대로 읽을 때, 모바일 사용 |
| **격자형 (Grid)** | 카드를 균일한 격자로 배치 | 깔끔하게 정리해서 볼 때 |

보드 상단의 레이아웃 전환 버튼으로 언제든 변경 가능합니다.

### 6-2. 학년도 기반 갤러리

갤러리는 **학년도(3월~다음해 2월)** 기준으로 자동 분류됩니다.

- 학생이 글을 작성하면 해당 시점의 학년도에 자동 배정
- 교사가 별도로 갤러리를 생성하거나 관리할 필요 없음
- 학년도 탭을 눌러 연도별 게시물 확인

## 7. 모바일 사용

### 7-1. 홈 화면에 앱 추가하기

**Android (크롬)**
1. 크롬으로 사이트 접속
2. 오른쪽 상단 메뉴(⋮) → **"홈 화면에 추가"**
3. 바탕화면에 초록색 돋보기 아이콘 생성

**iPhone (사파리)**
1. 사파리로 사이트 접속
2. 하단 공유 버튼(□↑) → **"홈 화면에 추가"**

### 7-2. 모바일 화면 특징

- 갤러리가 자동으로 **스트림형(세로 나열)**으로 표시됨 (레이아웃 전환 버튼 숨김)
- 학생 화면 하단에 3개 탭: 🏠 홈 / 🖼️ 갤러리 / 📓 내 기록
- 음성 입력은 크롬 브라우저에서만 지원

## 8. 기능 요약표

### 교사 기능

| 기능 | 설명 |
|------|------|
| 대시보드 | 미션 수, 학생 수, 초대 코드 확인 |
| 미션 만들기 | 제목, 설명, 기간, 레이아웃 설정 |
| AI 설명 생성 | 미션 제목으로 안내문 자동 작성 |
| 미션 보드 | 학생 관찰 일지 보기, 레이아웃 전환 |
| 갤러리 | 학년도별 전체 게시물 관리 |
| 학생 계정 생성 | 이메일/비밀번호 자동 생성 |
| 학생 계정 수정 | 이메일/비밀번호 변경 |
| 학생 삭제 | 체크박스 선택 후 일괄 삭제 |
| 새 학급 만들기 | 새 초대 코드 발급 |
| 게시물 삭제 | 부적절한 게시물 삭제 |

### 학생 기능

| 기능 | 설명 |
|------|------|
| 반 참여 | 6자리 초대 코드로 반 참여 |
| 관찰 일지 쓰기 | 사진 + 글 + 음성 입력 |
| 음성 입력 | 말로 관찰 내용 입력 (크롬) |
| 사진 첨부 | 최대 5장 업로드 |
| 날씨 선택 | 맑음/흐림/비/눈/바람 |
| 공개 설정 | 친구 공개 / 선생님만 |
| AI 칭찬 댓글 | 글 제출 즉시 AI가 칭찬 |
| 내 기록 | 내 관찰 일지 목록 확인 |
| 글 수정 | 작성한 글 수정 |
| 갤러리 | 친구 관찰 일지 감상 |

### AI 기능

| 기능 | 작동 방식 | 사용자 |
|------|----------|--------|
| 칭찬 댓글 생성 | 글 + 사진 분석 → 구체적 칭찬 + 질문 | 학생 글 제출 시 자동 |
| 미션 설명 생성 | 미션 제목 → 관찰 안내문 작성 | 교사가 버튼 클릭 |
