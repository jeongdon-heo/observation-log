## 1. 시작하기

### 회원가입

1. 첫 화면에서 **"회원가입"** 버튼을 누릅니다.
2. 이름, 이메일, 비밀번호(6자 이상)를 입력합니다.
3. 역할을 선택합니다: **"선생님"** 또는 **"학생"**
4. **"회원가입"** 버튼을 누르면 가입이 완료됩니다.

> 학생 계정은 교사가 직접 만들어줄 수도 있습니다. (교사용 가이드 참고)

### 로그인

1. 이메일과 비밀번호를 입력합니다.
2. **"로그인"** 버튼을 누르면 자동으로 대시보드로 이동합니다.
   - 교사 → 교사 대시보드
   - 학생 → 학생 대시보드

## 2. 교사용 가이드

### 2-1. 대시보드

로그인하면 대시보드가 표시됩니다. 한눈에 확인할 수 있는 정보:

| 항목 | 설명 |
|------|------|
| 전체 미션 | 만든 미션 수 |
| 진행중 미션 | 현재 진행 중인 미션 수 |
| 학생 수 | 반에 가입한 학생 수 |
| 학급 초대 코드 | 학생에게 알려줄 **6자리 코드** |

#### 학급 초대 코드

- 대시보드 하단에 큰 글씨로 표시됩니다.
- 이 코드를 학생들에게 알려주면, 학생이 직접 반에 참여할 수 있습니다.

#### 새 학급 만들기

새 학년이 시작되면:
1. 대시보드 하단의 **"새 학급 만들기"** 버튼을 누릅니다.
2. 새로운 초대 코드가 발급되고, 이전 학급의 갤러리는 자동 보관됩니다.
3. 이전 학급의 게시물은 갤러리에서 계속 열람할 수 있습니다.

---

### 2-2. 미션 관리

상단 메뉴의 **"미션 관리"**를 누릅니다.

#### 새 미션 만들기

1. **미션 제목**: 관찰 주제를 입력합니다. (예: "봄의 식물 관찰")
2. **설명**: 학생들에게 안내할 내용을 작성합니다.
   - **"AI 설명 생성"** 버튼을 누르면 제목을 바탕으로 AI가 자동으로 설명을 작성합니다.
3. **주차 라벨**: 선택 사항입니다. (예: "1주차", "4월 2주")
4. **보드 레이아웃**: 학생 일지를 어떤 형태로 볼지 선택합니다.
   - **담벼락형**: 패들렛처럼 자유롭게 배치
   - **스트림형**: 시간순 세로 나열
   - **격자형**: 카드를 균일한 격자로 배치
5. **시작일 / 마감일**: 학생이 글을 작성할 수 있는 기간을 설정합니다.
6. **"미션 만들기"** 버튼을 누르면 완료됩니다.

> 시작일~마감일 사이에만 학생이 글을 작성할 수 있습니다. 기간 밖에서는 미션 카드가 비활성화됩니다.

#### 미션 보드 보기

미션 카드를 클릭하면 해당 미션에 학생들이 작성한 관찰 일지를 볼 수 있습니다.
- 상단의 레이아웃 전환 버튼으로 보기 방식을 바꿀 수 있습니다.
- 부적절한 게시물은 **"삭제"** 버튼으로 삭제할 수 있습니다.

---

### 2-3. 갤러리

상단 메뉴의 **"갤러리"**를 누릅니다.

- 모든 학생의 관찰 일지를 학년도별로 볼 수 있습니다.
- **학년도 탭**을 눌러 연도를 전환합니다. (학년도: 3월 ~ 다음해 2월)
- 이전 학급의 게시물도 함께 표시됩니다.
- 게시물 삭제가 가능합니다.

---

### 2-4. 학생 관리

상단 메뉴의 **"학생 관리"**를 누릅니다.

#### 학생 계정 만들어주기

초등학생이 직접 회원가입하기 어려운 경우, 교사가 대신 계정을 만들 수 있습니다.

1. **학생 이름**을 입력하고 **"추가"** 버튼을 누릅니다.
2. 이메일과 비밀번호가 자동 생성됩니다.
3. 생성된 계정 정보가 표에 표시됩니다.
4. **"전체 복사"** 버튼을 눌러 정보를 복사한 뒤 학생에게 전달합니다.

> 이메일/비밀번호를 직접 지정하려면 "이메일/비밀번호 직접 설정"을 펼쳐 입력하세요.

#### 학생 계정 수정

- 교사가 만든 계정은 **"수정"** 버튼으로 이메일/비밀번호를 변경할 수 있습니다.
- 학생이 직접 가입한 계정은 수정할 수 없습니다.

#### 학생 삭제

1. 삭제할 학생의 체크박스를 선택합니다. (전체 선택도 가능)
2. **"선택 삭제"** 버튼을 누릅니다.
3. 삭제된 학생의 작성 글과 댓글은 유지됩니다.

## 3. 학생용 가이드

### 3-1. 반 참여하기

처음 로그인하면 반 참여 화면이 표시됩니다.

1. 선생님이 알려준 **6자리 초대 코드**를 입력합니다.
2. **"반 참여하기"** 버튼을 누르면 완료됩니다.

---

### 3-2. 관찰 일지 쓰기

홈 화면에 선생님이 만든 미션 목록이 표시됩니다.

1. **진행중인 미션 카드**를 눌러 글쓰기 페이지로 이동합니다.
   - "시작 전" 또는 "마감" 표시된 미션은 글을 쓸 수 없습니다.

2. **관찰 내용**을 작성합니다.
   - 직접 타이핑하거나, **"🎤 음성 입력"** 버튼을 눌러 말로 입력할 수 있습니다.
   - 음성 입력 버튼을 누르면 "🔴 듣는 중..." 상태가 됩니다.
   - 말하기를 마치면 자동으로 텍스트가 입력됩니다.
   - 더 말하려면 버튼을 다시 누르세요.

3. **사진 첨부** (최대 5장): 관찰한 대상의 사진을 올립니다.

4. **오늘 날씨**를 선택합니다: ☀️ 맑음 / ☁️ 흐림 / 🌧️ 비 / ❄️ 눈 / 💨 바람

5. **관찰 날짜**를 확인합니다. (기본값: 오늘)

6. **공개 여부**를 설정합니다.
   - 켜짐: 친구들에게 공개 (갤러리에 표시)
   - 꺼짐: 선생님만 볼 수 있음

7. **"관찰 일지 올리기"** 버튼을 누릅니다.

8. 잠시 후 **AI 선생님의 칭찬 댓글**이 팝업으로 표시됩니다!
   - "확인"을 누르면 홈으로 돌아갑니다.

---

### 3-3. 내 기록 보기

하단의 **"📓 내 기록"** 탭을 누릅니다.

- 내가 작성한 모든 관찰 일지를 볼 수 있습니다.
- **"수정"** 버튼으로 글을 수정할 수 있습니다.
- AI 선생님과 친구들의 댓글도 확인할 수 있습니다.

---

### 3-4. 갤러리 구경하기

하단의 **"🖼️ 갤러리"** 탭을 누릅니다.

- 우리 반 친구들이 공개한 관찰 일지를 구경할 수 있습니다.
- 내가 비공개로 쓴 글은 나에게만 보입니다.

## 4. 모바일에서 사용하기

### 홈 화면에 앱 추가하기

매번 브라우저를 열지 않아도, 바탕화면에서 바로 접속할 수 있습니다.

**Android (크롬)**
1. 크롬으로 사이트에 접속합니다.
2. 오른쪽 상단 메뉴(⋮)를 누릅니다.
3. **"홈 화면에 추가"**를 누릅니다.
4. 바탕화면에 초록색 돋보기 아이콘이 생깁니다.

**iPhone (사파리)**
1. 사파리로 사이트에 접속합니다.
2. 하단 공유 버튼(□↑)을 누릅니다.
3. **"홈 화면에 추가"**를 누릅니다.

### 모바일 화면 안내

- 모바일에서는 갤러리가 자동으로 **스트림형(세로 나열)**으로 표시됩니다.
- 학생 화면은 하단에 3개 탭이 있습니다: 🏠 홈 / 🖼️ 갤러리 / 📓 내 기록

## 5. 자주 묻는 질문

### 교사

**Q. 학생이 초대 코드를 잃어버렸어요.**
> 교사 대시보드에서 초대 코드를 확인하여 다시 알려주세요.

**Q. 새 학년이 시작되면 어떻게 하나요?**
> 대시보드의 "새 학급 만들기"를 누르면 새 초대 코드가 발급됩니다. 이전 학급의 데이터는 갤러리에서 계속 볼 수 있습니다.

**Q. 학생이 쓴 글을 삭제할 수 있나요?**
> 네, 미션 보드나 갤러리에서 게시물의 "삭제" 버튼을 누르면 됩니다.

**Q. AI 설명 생성이 안 돼요.**
> 인터넷 연결을 확인하고 다시 시도해주세요. 잠시 후에도 안 되면 직접 작성해주세요.

### 학생

**Q. 음성 입력이 안 돼요.**
> 크롬 브라우저를 사용해주세요. 마이크 권한을 허용해야 합니다. (Firefox는 지원하지 않습니다)

**Q. 미션 카드를 눌러도 글쓰기가 안 돼요.**
> 미션 기간이 아직 시작되지 않았거나 마감된 경우입니다. 카드에 "시작 전" 또는 "마감"으로 표시됩니다.

**Q. AI 선생님 댓글이 안 나와요.**
> AI 댓글 생성에 시간이 걸릴 수 있습니다. 잠시 기다려주세요. 댓글이 나오지 않아도 관찰 일지는 정상 저장됩니다.

**Q. 내 글을 삭제하고 싶어요.**
> 현재 학생은 글 삭제가 불가능합니다. 선생님에게 요청하세요.
